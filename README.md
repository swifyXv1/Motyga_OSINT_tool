# MOTYGA Scanner

A Python-based Telegram chat analytics tool built with Telethon.

## Features

- Username-based message statistics
- Chat ID retrieval
- User activity statistics
- JSON and TXT export
- Interactive command-line interface

## Technologies

- Python
- Telethon
- Asyncio
- JSON

## Installation

1. Clone the repository:

   `git clone https://github.com/swifyXv1/Motyga_OSINT_tool.git`

2. Install dependencies:

   `pip install -r requirements.txt`

3. Configure your Telegram API credentials using a local `.env` file.

4. Run the application:

   `python main.py`

## Privacy & Security

Use only with chats and data you are authorized to access. Do not publish session files, credentials, or private conversations.
